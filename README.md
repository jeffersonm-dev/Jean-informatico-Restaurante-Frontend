# Financial Consolidation - Frontend
![alt text](image.png)
Sistema de Control Financiero para Estaciones de Servicio - Frontend Vue 3

## 📋 Descripción

Financial Consolidation es un sistema completo para la gestión de reportes financieros de estaciones de servicio. Este frontend está construido con Vue 3 y proporciona una interfaz moderna y profesional para:

- Gestión de empresas y usuarios
- Carga y validación de reportes financieros
- Dashboard con indicadores clave
- Gestión de roles y permisos
- Bitácora de actividades
- Subida de archivos Excel y PDF


![alt text](image-1.png)
## 🚀 Tecnologías

- **Vue 3** - Framework progresivo para UI
- **Pinia** - Gestión de estado
- **Vue Router** - Navegación
- **Axios** - Cliente HTTP
- **Bootstrap Icons** - Iconos profesionales
- **SweetAlert2** - Alertas y modales
- **Vite** - Build tool

## 📦 Instalación

### Requisitos previos

- Node.js >= 18.0.0
- npm >= 8.0.0

### Pasos de instalación

```bash
# Clonar el repositorio
git clone https://github.com/fenix-core/financial-consolidation-frontend.git

# Entrar al directorio
cd financial-consolidation-frontend

# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env

# Iniciar servidor de desarrollo
npm run dev
